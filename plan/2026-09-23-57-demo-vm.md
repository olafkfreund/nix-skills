# Plan: a disposable NixOS demo VM for agentic coding

## Approved decisions

These come from the approved spec. The plan can be followed without opening
the intent or spec.

**Location.** A `demo/` subflake with its own committed `flake.lock`. The
main flake is unchanged. The demo is started with
`nix run github:olafkfreund/nix-skills?dir=demo`, which needs Nix 2.26 or
newer for relative path inputs.

**`demo/flake.nix`.**
- **Inputs:**
  - `nix-skills.url = "path:..";`
  - `nixpkgs.follows = "nix-skills/nixpkgs";`
  - `home-manager.follows = "nix-skills/home-manager";`
  - `llm-agents.url = "github:numtide/llm-agents.nix";` with no follows.
- **`nixConfig`:** the Numtide cache (`https://cache.numtide.com`, key
  `niks3.numtide.com-1:DTx8wZduET09hRmMtKdQDxNNthLQETkc/yaX7M4qK0g=`).
- **Outputs,** for `x86_64-linux` and `aarch64-linux`:
  - `nixosModules.demo = ./demo.nix`;
  - `nixosConfigurations.demo`, from `nixosSystem` with
    `home-manager.nixosModules.home-manager` and `./demo.nix`, and
    `specialArgs = { inherit nix-skills llm-agents; }`;
  - `packages.<system>.vm` and `.default`, the configuration's
    `system.build.vm`;
  - `apps.<system>.vm` and `.default`, running
    `${vm}/bin/run-nix-skills-demo-vm`;
  - `checks.<system>.vm-test`.

**`demo/demo.nix`.**
- **The `demo.agents` option,** an enum list of `claude-code`, `codex`,
  `opencode` and `gemini-cli`, defaulting to
  `[ "claude-code" "codex" "opencode" ]`.
  - The packages come from
    `llm-agents.packages.${pkgs.stdenv.hostPlatform.system}`. The binaries
    are `claude`, `codex`, `opencode` and `gemini`.
  - Skill directories: `claude-code` → `"claude"` and `codex` →
    `"codex"`. `opencode` → `"opencode"` only when neither of the other two
    is selected. `gemini-cli` gets no directory.
- **System:**
  - hostname `nix-skills-demo`;
  - `system.stateVersion`;
  - flakes enabled, plus the Numtide cache;
  - `virtualisation.podman.enable = true`;
  - system packages: the agents, `devenv`, `git` and `curl`.
- **User `demo`:**
  - `isNormalUser`, in the `wheel` group, with `initialPassword = "demo"`;
  - getty automatic login;
  - `services.openssh.enable = true`.
- **Home Manager for `demo`:**
  - imports `nix-skills.homeManagerModules.default`, with
    `programs.nix-skills = { enable = true; agents = <mapped>; }`;
  - `home.stateVersion`;
  - `~/example/README.md` (the start prompt and next steps), plus a minimal
    Python `devenv.nix` and `devenv.yaml`.
- **`virtualisation.vmVariant`:**
  - `memorySize = 4096`, `cores = 4`, `diskSize = 16384`;
  - `graphics = false`;
  - forward `127.0.0.1:2222` on the host to guest port 22.
- **No secrets anywhere.**

**VM test** (`pkgs.testers.runNixOSTest`, node `machine` with the same
modules and `specialArgs`). It checks:
1. `multi-user.target` and `home-manager-demo.service` are reached;
2. `su - demo -c 'timeout 60 <bin> --version'` succeeds for `claude`,
   `codex` and `opencode`;
3. `.claude/skills` and `.agents/skills` each hold the `skills.json`
   count, and `nix-workflow/SKILL.md` is readable;
4. `.config/opencode/skills` is absent;
5. `podman --version` and `devenv version` succeed, and
   `~/example/README.md` exists.

The test is offline.

**`.github/workflows/demo.yml`,** which is not a required check.
- **Triggers:**
  - `pull_request` and `push` to `main`, on the paths `demo/**`, `nix/**`,
    `skills/**`, `skills.json`, `flake.nix` and `flake.lock`;
  - weekly `schedule`;
  - `workflow_dispatch`.
- **Permissions:** `contents: read`.
- **Job `vm-test`:**
  - `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1` (v7.0.1),
    with `persist-credentials: false`;
  - `cachix/install-nix-action@13d8dd58da0234aa297dedd986986ccb8e7f3e24`
    (v31.11.1), with the Numtide substituter and key in `extra_nix_config`;
  - the KVM udev rule step, which fails clearly if `/dev/kvm` is missing;
  - `nix build ./demo#checks.x86_64-linux.vm-test -L --no-update-lock-file`;
  - `nix build ./demo#vm --no-update-lock-file`.

**Documentation.**
- **`docs/src/tutorials/demo-vm.md`** ("Try it in a demo VM"), listed in
  `SUMMARY.md` after Getting started. It covers:
  - the requirements: KVM, Nix 2.26 or newer, and the measured sizes;
  - `nix run`;
  - logging in (the console logs in automatically; or
    `ssh -p 2222 demo@127.0.0.1` with password `demo`, loopback only);
  - adding a key;
  - `~/example` and the start prompt;
  - resetting by deleting `nix-skills-demo.qcow2`;
  - changing the agents in a clone;
  - the limits: the Gemini CLI gap, and that it is not a hardened sandbox.
- **AGENTS.md:** a `demo/` line.
- **CONTRIBUTING.md:** one line saying the demo lock is updated
  deliberately and on its own, and that lock-only bumps are exempt.

## Steps

1. **`demo/demo.nix`.**
   → Verify: it parses (`nix-instantiate --parse`).
2. **`demo/flake.nix`,** then `nix flake lock ./demo`. Stage both.
   → Verify:
   - `nix flake show ./demo` lists the module, the configuration, `vm`,
     the apps and `vm-test` for both systems;
   - `nix build ./demo#vm` succeeds;
   - `nix eval ./demo#nixosConfigurations.demo.config.home-manager.users.demo.programs.nix-skills.agents`
     prints `[ "claude" "codex" ]`.
3. **The VM test.**
   → Verify: `nix build ./demo#checks.x86_64-linux.vm-test -L` passes
   locally (this machine has `/dev/kvm` and the `nixos-test` feature).
   - If an agent cannot print `--version` offline, switch that agent's
     check to `command -v <bin>` and record it as a deviation in this plan,
     in the same commit.
4. **A real boot, headless.** Run
   `timeout 240 ./result/bin/run-nix-skills-demo-vm` with its console
   captured to a log, from a scratch directory so the qcow2 lands there.
   → Verify: the log shows an automatic login for `demo` on
   `nix-skills-demo`. Then delete the scratch qcow2. Record the sizes:
   `nix path-info -Sh ./demo#vm` for the closure, and the configured RAM and
   disk.
5. **`.github/workflows/demo.yml`.**
   → Verify: `actionlint` is clean, and the only permission is
   `contents: read`.
6. **The tutorial page, `SUMMARY.md`, AGENTS.md and CONTRIBUTING.md,** with
   the measured sizes.
   → Verify: `nix build .#docs` succeeds (links, anchors, style), and
   `check_collection.py` passes.
7. **Full checks:** unit tests, `check_collection.py`, `devenv shell
   check-fast`, `nix flake check` for the main flake (unchanged, so it must
   still pass), and `nix build .#nix-skills --no-link`. Commit in logical
   groups, push, and open a PR.
   → Verify:
   - `collection-check` is green, and the PR is `CLEAN`;
   - `demo.yml` passes on the PR, and if it does, the PR says
     `Closes #57`;
   - if `demo.yml` fails only because KVM is missing, re-run it once, then
     report the result.

   Do not merge without approval.
